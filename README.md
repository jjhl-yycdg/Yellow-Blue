# OC Showcase — 纯静态原型

这是一个纯静态原型，演示了相册和图片上传/展示/编辑的前端交互，所有数据保存在浏览器的 IndexedDB 中（不依赖后端）。

如何使用
- 打开 `index.html`（直接在浏览器中打开文件）。
- 将图片拖放到左侧的上传框，或点击“选择文件”。上传时会提示填写画师名、米画师ID 和相册名（可输入新相册名）。
- 上传后，左侧会列出相册，点击相册可查看画廊。点击图片会打开可编辑的元数据模态窗口。
- 点击画师名会跳转到显示该画师所有作品的页面。

备注与限制
- 图片和元数据仅保存在当前浏览器的 IndexedDB 中，换设备或清理浏览器数据将丢失。
- 这是一个最小可行原型，适合快速验证交互与流程；若需持久化/多人共享，请确认并切换到后端存储方案（例如 Node+SQLite）。

暗/亮切换
- 页面右上角有暗/亮主题切换按钮，选择会被保存到浏览器的本地存储（localStorage），下次打开会保留你的偏好。
